# Project Repository

This is the initial README file for the project.

## Frontend environment

See `frontend_web_ui/.env.example` for available environment variables. Key flags:
- `REACT_APP_API_BASE`: Backend base URL (default http://localhost:3001)
- `REACT_APP_VOICE_ENABLED`: Enable/disable voice UI (default true)
- `REACT_APP_TTS_AUTO_SPEAK`: Auto-speak AI responses (default true)
